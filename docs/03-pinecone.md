# 03 — Pinecone Setup

## 1. Create the account and key

1. Sign up at https://app.pinecone.io (the free Starter plan is enough for this project).
2. Go to **API Keys** → **Create API key** and copy it.
3. In `.env`:

```env
VECTOR_STORE=pinecone
EMBEDDING_PROVIDER=pinecone
PINECONE_API_KEY=pcsk_...your key...
PINECONE_INDEX=ops-assistant
PINECONE_NAMESPACE=tenant-demo
PINECONE_CLOUD=aws
PINECONE_REGION=us-east-1
PINECONE_EMBED_MODEL=multilingual-e5-large
MIN_SCORE=0.80
```

You don't create the index by hand. On first start, the code creates a **serverless** index with dimension 1024 and the cosine metric, which match `multilingual-e5-large`.

> Embeddings are generated by Pinecone's hosted inference API, so you need no OpenAI key. Check Pinecone's current pricing page for the free-tier inference allowance. This project uses only a few thousand tokens.

## 2. Load documents and check the index

```bash
rmdir /s /q data         # Windows: start with a fresh catalog   (macOS/Linux: rm -rf data)
python scripts/ingest.py
```

In the Pinecone console, open the index and choose **Browse** with namespace `tenant-demo`. Each record has metadata such as `title`, `section`, `allowed_groups`, `lifecycle`, `flagged` and `chunk_text`.

## 3. Calibrate the abstention threshold (important)

Each embedding model scores differently: e5 similarity is usually high even for unrelated text. So measure it:

```bash
python scripts/evaluate.py --calibrate
```

Output looks like:

```
answerable   min=0.8xx avg=0.8xx
unanswerable max=0.7xx avg=0.7xx
-> choose MIN_SCORE between the unanswerable max and the answerable min.
```

Set `MIN_SCORE` in `.env` to a value between those two numbers, restart, then run:

```bash
python scripts/evaluate.py -v
```

The measured Pinecone results for this project are recorded in [Evaluation results](EVALUATION.md). Re-run the evaluation if you change the corpus, model, or configuration; do not treat the current measurements as results for a different setup.

If the two ranges overlap, which is common with only 9 documents, add more unanswerable questions to `eval/questions.json` and choose the threshold that keeps leakage at 0 while answering most questions. Treat it as a trade-off, and explain it as one in interviews.

## 4. How the metadata filter works

```python
{"$and": [
  {"allowed_groups": {"$in": ["all"]}},     # from the API key, never from the user
  {"lifecycle": {"$eq": "ACTIVE"}},
  {"flagged": {"$eq": False}}
]}
```

`allowed_groups` is stored as a list of strings, and `$in` matches if any group overlaps. The namespace (`tenant-demo`) separates tenants, but it is not a security control by itself.

## Common errors

| Error | Cause / fix |
|---|---|
| `Index ... has dimension 384 but the embedding model produces 1024` | You changed models. Use a new `PINECONE_INDEX` name. |
| 401 / Unauthorized from Pinecone | Wrong or expired key in `.env` |
| Results empty right after ingest | Serverless indexes take a few seconds to update; retry |
| Everything abstains | `MIN_SCORE` too high; rerun `--calibrate` |
